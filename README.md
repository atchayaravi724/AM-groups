## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or serve it using Python or any static web server:

```bash
# Using Python 3
python3 -m http.server 8000

# Then open http://localhost:8000 in your browser
```

- **Vercel**
- **Cloudflare Pages**
- Any cPanel / Apache / Nginx web hosting
